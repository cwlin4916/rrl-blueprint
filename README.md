# Blueprint — a tamely ramified local relative Langlands conjecture

The rendered blueprint for *On a tamely ramified local relative Langlands conjecture via categorical representations* (Milton Lin, Toan Pham, Jize Yu).

**Read it at <https://cwlin4916.github.io/rrl-blueprint/>.**

The blueprint is the project's reasoning tree, not the manuscript. Every lemma the main theorem rests on is a node with its own page: a precise statement, its dependencies, the write-up, the referee reports it has survived, and a confidence derived from that record rather than asserted.

Start at [the DAG](https://cwlin4916.github.io/rrl-blueprint/dag.html) for the shape of the argument, or at [Concepts](https://cwlin4916.github.io/rrl-blueprint/concepts/) for what a node, a closed world and a confidence mean here.

## About this repository

Every file here is generated by `tools/build_dag_site.py` in the project's source repository, which is private. Nothing on the site is hand-edited, and edits made here would be overwritten by the next publish.

The manuscript itself is not part of this site.
